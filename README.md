# mn-sv

The overview page of the MilitärNews tools for editors and customers: Newsmix, viz, the Footer Bot,
litfass, Tartaros and the handbook. German with an English switch.

The projects and all texts are in `src/lib/projects.ts`; pictures are in `static/img/`.

```sh
bun install
bun run dev
bun run build
```

Deployed on Vercel from `main`.
