# Brand assets

Source files for MilitärNews branding.

| File                                          | What it is                                                  |
| --------------------------------------------- | ----------------------------------------------------------- |
| `mn-wide.xcf`                                 | Wide logo artwork (GIMP source).                            |
| `mn-talk-31-03-2023_font-hp-simplified-4.xcf` | Talk/graphic source from 31 March 2023 using HP Simplified. |
| `BlackedOut-Regular.otf`                      | BlackedOut regular typeface.                                |

These are masters, not web assets. Export PNG/SVG/WOFF2 versions into `static/` when a design needs
them; do not ship the XCF/OTF masters to the browser.
